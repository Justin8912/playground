Codenames
==
A personal implementation of the board game Codenames using a serverless architecture on AWS. 

The application uses:
1. AWS Appsync with cognito user pool authentication
2. AWS lambdas for complex business logic 
3. AWS DynamoDB for data storage and quick access
4. Vite + React and Amplify for the frontend UI
5. Tailscale for networking
